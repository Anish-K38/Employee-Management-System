Employee Leave Management System
Overview

This  Employee Leave Management System built using the MERN stack. It helps organizations manage employee leave requests through a streamlined approval workflow.

Employees can apply for leaves, track their leave history, and monitor remaining leave balances. Administrators can review, approve, reject, and manage leave requests through a centralized dashboard.

This project demonstrates authentication, authorization, REST API development, database design, dashboard analytics, and deployment-ready architecture.
